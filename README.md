# 단단상회 주문/상품 사이트 — 시작 가이드

Next.js(App Router) + Google Sheets(상품 DB) + Cloudinary(이미지) 조합입니다.
전부 무료 플랜으로 운영 가능합니다.

## 폴더 구조

```
dandan-shop/
├─ app/
│  ├─ page.jsx                 메인: 날짜탭 + 상품 목록
│  ├─ layout.jsx
│  ├─ globals.css
│  ├─ product/[id]/page.jsx    상품 상세페이지
│  └─ reservations/page.jsx    예약 검색 페이지
├─ lib/
│  └─ sheet.js                 구글시트 CSV 불러와서 파싱
├─ package.json
└─ .env.local.example
```

## 1단계 — 구글 시트 두 개 준비

### ① 상품마스터 시트

열 순서를 **정확히 이대로** 만들어주세요 (1행은 헤더). 옵션은 최대 8개(`option1`~`option8`,
`price1`~`price8`)까지 쓸 수 있고, 안 쓰는 옵션 칸은 비워두면 됩니다:

| id | date | category | name | status | image | description | shiping fee | option1 | price1 | option2 | price2 | ... |
|----|------|----------|------|--------|-------|-------------|-------------|---------|--------|---------|--------|-----|
| p001 | 2026-08-19 | 수산물 | 완도활전복 1kg | 주문가능 | https://res.cloudinary.com/.../abalone.jpg | 완도산 자연산 전복입니다.<br>당일 수급 당일 발송 | 3000 | 5~6미 | 33400 | 6~7미 | 31600 | ... |

- `id` : 상품마다 고유값 (p001, p002... 그냥 순서대로 적으면 됨)
- `category` : 수산물 / 농산물 / 김치 / 젓갈 / 과일 / 가공식품 중 하나
- `status` : 주문가능 / 품절 / 시즌종료 중 하나
- `description` : 줄바꿈하고 싶은 곳에 `<br>` 넣으면 상세페이지에서 줄바꿈으로 나옵니다
- `shiping fee` : 이 상품 주문 1건당 붙는 배송비(원). 무료배송이면 0. (열 이름 철자 그대로 써야 합니다)
- `option1~8` / `price1~8` : 옵션명과 그 옵션의 가격. 옵션이 하나뿐이어도 `option1`/`price1`에만 채우면 됩니다.
  목록 화면·상세페이지에는 옵션 중 최저가가 "○○원부터"로 표시되고, 주문 화면에서 고객이 옵션을 선택합니다.

### ② 예약기록 시트

| nickname | item | status | date |
|----------|------|--------|------|
| 딸기맘 | 활전복 2미 | 결제완료 | 2026-08-18 |

## 2단계 — 시트를 "웹에 게시(CSV)"로 공개

각 시트에서:
`파일 → 공유 → 웹에 게시 → 시트 선택 → 형식: 쉼표로 구분된 값(.csv) → 게시`

게시하면 나오는 URL을 복사해서 `.env.local`에 넣습니다 (아래 3단계).

> 이 방식은 API 키/인증 설정이 전혀 필요 없어서 가장 빠르고 안정적입니다.
> 시트 자체를 "링크가 있는 모든 사용자에게 공개"로 바꿀 필요는 없습니다 — 웹 게시는 별도 권한입니다.

## 3단계 — 이미지 준비 (Cloudinary)

1. cloudinary.com 무료 가입
2. 대시보드에서 이미지 업로드 (또는 Media Library에 드래그)
3. 업로드된 이미지의 URL 복사 → 상품마스터 시트 `image` 열에 붙여넣기

기존에 카페24/쿠팡에 올려둔 상품 사진 URL이 있다면 그걸 그대로 써도 됩니다.

## 4단계 — 로컬 설정

```bash
cd dandan-shop
npm install
cp .env.local.example .env.local
```

`.env.local`을 열어서 2단계에서 복사한 CSV 게시 URL 두 개를 넣습니다:

```
PRODUCTS_CSV_URL=https://docs.google.com/spreadsheets/d/e/.../pub?output=csv
RESERVATIONS_CSV_URL=https://docs.google.com/spreadsheets/d/e/.../pub?output=csv
```

```bash
npm run dev
```

`http://localhost:3000` 에서 확인.

## 5단계 — Vercel 무료 배포

1. 이 폴더를 GitHub 저장소로 push
2. vercel.com → New Project → 방금 만든 저장소 선택 → Import
3. Environment Variables에 `.env.local`과 똑같이 두 개 추가
4. Deploy 클릭

몇 분 뒤 `단단상회.vercel.app` 형태(또는 랜덤 이름)로 바로 접속 가능. 나중에 실제 도메인 연결도 Vercel 설정에서 무료로 가능합니다.

## 6단계 — 주문/결제(계좌이체) 연동

카드결제 PG 없이 계좌이체 + 수동 확인 방식입니다.
발송인(주문자)과 수취인(받는 분) 정보를 따로 받아서, 선물 발송 같은 경우도 처리할 수 있습니다.

1. **예약기록 시트 헤더를 이렇게 만드세요** (총 16열, 순서 정확히):
   ```
   아이디 | 주문일시 | 발송인 | 발송인 주소 | 발송인 전화번호 | 수취인 | 수취인 전화번호 | 수취인 주소 |
   카테고리 | 구매품목 | 수량 | 구매가격 | 배송비 | 합계금액 | 결제상태 | 발주 상태
   ```
   - `아이디` / `주문일시` / `결제상태`(입금대기 → 입금확인) / `발주 상태`(발주대기 → 발송완료)는
     아래 Apps Script가 주문이 들어올 때마다 자동으로 채웁니다. 직접 입력할 필요 없어요.
   - `발송인`은 실제 입금하실 분과 동일한 이름으로 받습니다 (입금자명 대조용).

2. 예약기록 시트에서 **확장 프로그램 → Apps Script** 열기 → 기본 코드 지우고
   `scripts/AppsScript.gs` 내용을 그대로 붙여넣기 → 저장

3. 오른쪽 위 **배포 → 새 배포** → 유형: **웹 앱** 선택
   - 실행 계정: 나
   - 액세스 권한: **모든 사용자**
   - 배포 클릭 → 권한 승인 → 나온 **웹 앱 URL** 복사

4. `.env.local`에 추가:
   ```
   ORDER_WEBHOOK_URL=(3번에서 복사한 URL)
   NEXT_PUBLIC_BANK_NAME=00은행
   NEXT_PUBLIC_BANK_ACCOUNT=000-0000-0000
   NEXT_PUBLIC_BANK_HOLDER=단단상회
   ```
   배송비는 여기서 설정하지 않습니다 — 1단계 상품마스터 시트의 `shipping` 열에서 상품마다 따로 설정하세요.

5. 상품 상세페이지 → "계좌이체로 주문하기" → 고객이 아래 정보를 입력합니다:
   - 수량
   - 발송인(주문자) 성함 / 전화번호 / 주소
   - 수취인(받는 분) 성함 / 전화번호 / 주소 (발송인과 같으면 체크박스로 자동 복사)

   접수되면 예약기록 시트에 한 줄이 자동으로 추가됩니다 — 주문번호(`ORD-0001`부터 순번),
   주문일시, 카테고리·품목·수량·구매가격·배송비·합계금액, 결제상태 **"입금대기"**, 발주 상태 **"발주대기"**.

6. 입금 확인되면 **시트에서 해당 행의 결제상태 칸을 "입금확인"으로 직접 수정**.
   발송 준비/완료되면 **발주 상태 칸을 "발송완료"** 등으로 직접 수정하면 끝.
   고객은 "내 주문 확인"에서 **주문번호(아이디) 또는 발송인/수취인 성함**으로 검색해
   결제상태·발주 상태를 볼 수 있습니다 (주소·전화번호 같은 개인정보는 검색 결과 화면에 노출되지 않습니다).

> Apps Script를 수정해서 배포할 때마다(코드 변경 시) "새 배포"가 아니라
> 기존 배포 옆의 **수정(연필 아이콘) → 새 버전**으로 업데이트해야 URL이 안 바뀝니다.

> 예약기록 시트가 "웹에 게시(CSV)"로 공개되어 있으므로(2단계), 개인정보 보호를 위해
> 검색 결과 화면에는 항상 최소한의 정보(주문번호·품목·상태)만 보여주도록 되어 있습니다.
> 시트 원본에는 주소·전화번호가 그대로 남아있으니, 게시 URL이 외부에 유출되지 않도록 주의하세요.

## 데이터 갱신 주기

메인 페이지는 60초마다 자동으로 최신 시트 내용을 다시 불러옵니다 (`revalidate: 60`).
시트에 상품 추가 → 최대 1분 안에 사이트에 반영됩니다. 더 즉시 반영이 필요하면
Google Apps Script로 Vercel의 On-Demand Revalidation을 호출하는 방법도 있는데,
필요하시면 다음 단계로 추가해드릴게요.
